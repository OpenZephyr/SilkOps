# Claude Code

Native packaging: `.claude-plugin/plugin.json` and `marketplace.json` at the repo root (`claude plugin marketplace add OpenZephyr/SilkOps`). Alternative without the plugin system: `silkops install-agent claude-code` links the skills into `~/.claude/skills` (or `.claude/skills` with `--scope repo`). Conventions: `AGENTS.md`, imported by the one-line `.claude/CLAUDE.md` (a root `CLAUDE.md` inside a plugin is not loaded and fails strict validation; consumer repos still get a root `CLAUDE.md` from `silkops conventions`). Checked 2026-09-23 against Claude Code plugin and skill discovery.
